# Non-goals

Current, not permanent: half the original list was later built.


- TUI or web UI.
- Remote or HTTP contexts: sync a directory instead.
- Subtask IDs (`24.1`); use `parent`.
- Milestones.
- Wizards or prompts.
- Configurable statuses.
- Moving tickets between repositories: `suggest` there, `archive` here.
- Writing directly into another branch's worktree.
