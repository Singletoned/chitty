## Description

A passed review must land on `main` as a fast-forward, never a merge commit. Being fast-forwardable is part of passing.

`chitty run --mode review` already rebases the branch onto `main` before the reviewer starts (`_prepare_review` in `src/chitty/run.py`). But `main` can move while the review runs, and the guides just say "merge its branch into `main`", so reviewers make `--no-ff` merges.

Change the guidance so that a reviewer passing a ticket:

1. Brings the branch up to date with `main`, by `git rebase main` or `git merge main` in the ticket's worktree. On a conflict that the reviewer can't resolve without changing the work, fail the review with cause `integration`.
2. Runs the repository's check again in the worktree. If it fails, fail the review.
3. From the main checkout, runs `git merge --ff-only <branch>`. If that refuses because `main` moved again, go back to step 1.

Files:
- `src/chitty/roles/review.md`, the "On a pass" bullet.
- `src/chitty/guide.md`, the "On a pass, merge the branch into `main`" sentence. This is the managed block that `chitty init` writes into `AGENTS.md`. Re-run `chitty init` here so this repo's `AGENTS.md` picks it up.
- The review section of `PLAN.md` (`grep -n '^## ' PLAN.md`): record the decision and why. Fast-forward keeps history linear, and the reviewed commits are exactly the ones that land.
- `src/chitty/__init__.py`: bump `__version__` at patch level, because the managed guide block changes (see `AGENTS.md`).

Out of scope:
- Making `chitty run` do the merge itself, or check that it was fast-forward.
- Setting `merge.ff` in any Git config.

## Acceptance Criteria

- [ ] `src/chitty/roles/review.md` and `src/chitty/guide.md` tell a reviewer to update the branch from `main`, re-run the check, then `git merge --ff-only`, and to repeat if `main` moved. A test in `tests/` asserts that `chitty guide review` and the `AGENTS.md` block that `chitty init` writes both contain `--ff-only`.
- [ ] `PLAN.md`'s review section records the fast-forward-only rule and why, and no guide or `PLAN.md` text still tells reviewers to make a merge commit (`grep -rn 'no-ff' src PLAN.md AGENTS.md` finds nothing).
- [ ] `__version__` in `src/chitty/__init__.py` is bumped at patch level, and this repo's `AGENTS.md` is regenerated by `chitty init`.
