## Description

Agents mark their own tickets done from review, here and in other repos. No ticket in this repo had a 'Reviewed:' note before 2026-10-28; TASK-39 to 42 went from review to done with only the author's 'Ready for review' note. The guide already says 'Never review a ticket you worked on', but in passing. Options: stronger, more prominent guide wording (review needs a fresh session that did not write the code, and an agent that finishes work stops at review); and/or have edit refuse review -> done without a note starting 'Reviewed:'. A note can't prove who reviewed, so this only makes skipping review deliberate.
