## Description

`plan.md` tells planners to re-check claims about other tickets just before promoting, because they can land during the read. When `chitty edit -s todo` runs, print the current status and title of every ticket ID mentioned in the description and criteria, so the planner sees changes without being told to look. Then remove the instruction.
