## Description

A ticket blocked after three failed reviews should preserve what the planning stage could have done to prevent the repeated failures.

## Acceptance Criteria

- [ ] When the review limit blocks a ticket, the blocking note requests a concise retrospective lesson.
- [ ] The retrospective distinguishes a plan gap, review gap, or worker error and identifies the preventable cause.
- [ ] The planning guide directs planners and cold readers to consult the accumulated lessons before accepting a new ticket.
- [ ] The lesson is stored in a durable project-level file that future agents can read.
